# Private object storage

`ObjectStorage` in `src/lib/storage.ts` exposes signed upload/download, head, stream, copy, put and delete. Its S3 adapter accepts a standard endpoint, region, bucket and access/secret pair. Production can supply an S3-compatible endpoint such as R2 and credentials without changing Product or Asset logic. Production integration still needs environment-specific CORS, credential rotation, backups and operational review. Real credentials belong in secret configuration, never Git.

The local provider is LocalStack S3 in this SaaS-only Compose stack, with a separate persistent volume. A small loopback gateway on `127.0.0.1:9000` verifies SigV4 signatures, rejects anonymous and expired requests, allows the UI's local origin for direct uploads, and forwards valid S3 operations to the internal provider. Both dev and test buckets are initialized as private; tests use `TEST_OBJECT_STORAGE_BUCKET` and cannot overwrite the dev bucket. The emulator's internal port is not published. This setup is for local development, not a public edge gateway.

Controlled multi-PC remote testing can configure `OBJECT_STORAGE_PUBLIC_ENDPOINT` for browser PUT/GET/UploadPart signatures while server operations keep using `OBJECT_STORAGE_ENDPOINT`. `OBJECT_STORAGE_ALLOWED_ORIGINS` configures exact local/remote browser origins for the gateway and buckets. Follow [remote-test storage](../remote-test-storage.md) for the additional tunnel route, required Host preservation and restart steps. This is local test infrastructure and does not satisfy Phase 9 production storage acceptance.

Staging keys follow `pending/workspaces/{workspaceId}/products/{productId}/assets/{assetId}/versions/{versionId}/upload`; finalized originals and thumbnails follow `workspaces/{workspaceId}/products/{productId}/assets/{assetId}/versions/{versionId}/...`. Every segment is an internal ID. `createUploadIntent` first checks session, selected workspace, membership, edit permission, Product ownership, and (for replacement) Asset ownership. `getAuthorizedDownload` does the same for read permission and verifies the current ready object exists. Image links last 60 seconds; video links last five minutes to permit seeking. A copied URL remains a bearer capability until it expires; anyone holding a currently valid URL can use it. API authorization prevents another workspace from obtaining one.

The bucket has no permanent public URL. The gateway and provider must never be exposed directly as a production internet service without a separate security design. Local tests verify unsigned reads, forged signatures, expired links and cross-workspace URL issuance.
