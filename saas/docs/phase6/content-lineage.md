# Immutable content lineage

Each current or historical ContentVersion retains its exact successful JobArtifact and job. AI Video also retains Product ID, ProductVersion, RuleVersion, used reference AssetVersions, provider policy, tier, aspect ratio and input hash. Duration and geometry come from the finalized artifact. Review loads the frozen Product snapshot from that version's job and signs only reference rows used by that execution. Editing today's Product or replacing its assets cannot substitute newer context.

Clip versions retain SourceAsset ID and SHA, optional frozen Product text/rules, transcript artifact/fingerprint, clip-plan artifact, selection spans/hook/reason/score/tags, analyzer policy/provider/models/usage, render policy and pipeline version. Internal analyzer/provider fields stay in bounded server metadata and are omitted from customer detail projections. Existing Clipper execution snapshots contain no binary Product references, so review shows the frozen textual context and explains that no reference images were used. Generic clips show source identity, original private preview and selection details.

`GENERATED_FROM` links an AI Video item to its original job. `CLIPPED_FROM` links a Clip item to its source; its version retains job and transcript/plan details. `VARIANT_OF` links a child item to one existing parent. These are immutable same-workspace relations. Registering a variant only records lineage; it never invokes generation.

Owner/Admin/Editor may register active same-workspace items. Repeating the same edge is idempotent; a different parent for a child that already has a parent returns 409. Archived items cannot receive new variant links. Existing links remain visible when an item is archived. API and database use a workspace advisory lock and bounded ancestor traversal. Self-links, cycles and chains that reach the 64-ancestor traversal bound are rejected. Composite foreign keys also reject cross-workspace edges even for direct database writes.

The detail page shows origin job, frozen Product/version, source, artifact/checksum and parent/variant links. Job pages display links to published items. It does not build a branching editor or graph visualization. Histories and relation displays are bounded to the latest 100 decisions/versions and 100 relations; all history remains stored. The simple variant selector offers the newest 24 active workspace items; the authorized API supports any valid active same-workspace parent ID.
